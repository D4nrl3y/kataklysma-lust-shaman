# Kataklysma Separated Sprites & Models Pack v2.1

Pacote reorganizado com **sprites** e **modelos** separados para facilitar uso em pipeline de produção.

## Estrutura
- **01_Models/**
  - **Turnarounds/**: vistas principais do modelo da personagem
  - **Portraits/**: portraits e cut-ins
  - **Details/**: mão e pé troll
  - **Equipment/**: cajado xamânico
- **02_Sprites/**
  - **Sheets/**: folhas de sprites para movimentação, combate e casting
- **03_Promotional_CG/**: materiais promocionais e pranchas conceituais
- **04_References/**: screenshots originais de referência

## Observação
Os arquivos de “modelos” aqui são **renders/model sheets** da personagem, não arquivos 3D nativos (.blend/.fbx/.obj).
