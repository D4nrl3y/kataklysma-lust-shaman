# Map backgrounds v001

There is one concept background for each first-pass zone. These images establish composition, landmarks and usable staging areas; they are not yet the final collision/TileMap layer.

Before importing into a playable Godot scene, each zone needs:

- collision polygons or a TileMap collision layer;
- separate foreground/decor assets;
- named interaction markers;
- NPC routes and spawn points;
- encounter regions;
- quest/event state hooks.

The zone catalogue and required landmarks are in `03_GODOT/data/zones.json` and `03_GODOT/MAP_PRODUCTION_SPEC_V001.md`.
