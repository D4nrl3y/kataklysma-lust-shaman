# Godot 4 — Kataklysma

1. Copie `assets/` para o projeto Godot.
2. Confirme que os sprites estão em `res://assets/kataklysma/sprites/`.
3. Crie um `AnimatedSprite2D`.
4. Use `kataklysma_spriteframes_setup.gd` para gerar `idle`, `walk`, `cast` e `combat`.
5. Mantenha o canvas de 543×362 px e o pivô em bottom-center para preservar o alinhamento.

Os frames da pasta principal vêm da versão `v3.2 SPRITEFIX`, que corrige os recortes da versão anterior.
