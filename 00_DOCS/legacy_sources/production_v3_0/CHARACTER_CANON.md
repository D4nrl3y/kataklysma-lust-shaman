# Character Canon — Kataklysma

- Nome oficial: **Kataklysma**
- Classe-base: Shaman
- Pele: azul/lavanda
- Cabelo: loiro/platinado, rabo de cavalo alto
- Olhos: âmbar/dourado
- Orelhas: longas, pontiagudas, com argolas/adornos
- Presas: inferiores, pequenas
- Silhueta: atlética, musculosa e curvilínea
- Mãos: **1 polegar + 2 dedos**
- Pés: **2 dedos**
- Roupa-base: couro, pele, penas, contas, dentes/osso
- Linguagem visual: tribal, xamânica, sombria e progressivamente corrompida

Toda arte nova deve preservar rosto, proporções, anatomia troll e paleta-base deste pacote.
