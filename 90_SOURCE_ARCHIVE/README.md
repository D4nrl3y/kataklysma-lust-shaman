# Source archive

Versioned legacy material retained for recovery and comparison:

- `legacy/` — prior production versions and their original exports.
- `generated_sprites/` — earlier sprite-generation batches.
- `raw_exports/` — raw image exports that may be useful for reprocessing.

Use `01_ASSETS/` for current production assets. Do not reference archive files directly in Godot unless intentionally testing an older version.
