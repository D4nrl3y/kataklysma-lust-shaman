# KATAKLYSMA — MASTER CHARACTER PACK v1.0

Projeto: Lust Shaman's Journey
Personagem: Kataklysma
Classe: Shaman
Uso: referência visual canônica para concept art, CGs, portraits, sprites e materiais promocionais.

## REGRAS CANÔNICAS
- Nome correto: **Kataklysma**.
- Troll adulta, alta, atlética e curvilínea.
- Pele azul/lilás fria e uniforme.
- Olhos âmbar/amarelo-dourado.
- Cabelo muito claro (loiro-platinado/branco), longo, volumoso e parcialmente preso no alto.
- Orelhas longas e pontiagudas com argolas douradas.
- Pequenas presas inferiores visíveis.
- Proporções corporais devem permanecer consistentes: busto cheio, cintura marcada, quadris amplos, pernas fortes/atléticas.
- **Mãos troll: 3 dígitos no total — 1 polegar + 2 dedos.**
- **Pés troll: exatamente 2 dedos.**
- Equipamento-base: couro, pele, penas, amuletos e metais tribais em tons terrosos.
- Cajado-base: madeira/osso, ornamentos tribais e foco/cristal de energia violeta.
- Render principal: 3D/CG realista de fantasia, iluminação cinematográfica e materiais detalhados.
- Sprites 2D devem preservar a mesma silhueta, cabelo, cores, proporções e anatomia troll.
- Materiais promocionais principais: proporção 16:9.
- Nunca alterar rosto, estrutura corporal, quantidade de dedos ou proporções entre artes sem revisão da ficha-mestra.

## CORRUPÇÃO VISUAL
- 0–20: normal.
- 21–40: sinais iniciais.
- 41–60: transformação perceptível.
- 61–80: corrupção avançada.
- 81–100: forma final.

## OBSERVAÇÃO DE PRODUÇÃO
Este pacote é uma bíblia visual 2D/CG. Para produção no Godot, os próximos ativos ideais são PNGs isolados em fundo transparente, sprite sheets padronizadas e, se necessário, um modelo 3D rigado derivado destas referências.
