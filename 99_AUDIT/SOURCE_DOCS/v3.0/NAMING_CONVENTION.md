# Asset Naming Convention

Padrão: `categoria_personagem_tipo_estado_frame_versao.ext`

Prefixos usados:
- `chr_` — character asset
- `ui_` — portrait/cut-in/interface
- `prop_` — equipamento/prop
- `cg_` — cinematic/concept/promo
- `ref_` — referência

Exemplos:
- `chr_kataklysma_spr_walk_f003_v001.png`
- `chr_kataklysma_rnd_front_v001.png`
- `ui_kataklysma_portrait_corrupted_v001.png`
- `prop_kataklysma_weapon_shaman_staff_v001.png`
- `cg_lsj_keyart_16x9_v001.png`

Frames usam `f001`, `f002` etc. Versões usam `v001`, `v002` etc.
