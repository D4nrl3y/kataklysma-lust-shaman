# NPC asset pack v001

Each named lore character has a neutral full-body render in `renders/`.

Runtime sprite frames are in `../../sprites/npcs/<character>/`:

- `IDLE/` — 4 frames
- `WALK/` — 4 frames
- `SHEETS/` — combined 4x2 sheet, 543x362 cells

All assets are first-pass visual direction and use the `v001` suffix where applicable.
