# Narrative CG variants

Production CGs live here. Every scene must contain four distinct images:

1. `01_start`
2. `02_development`
3. `03_climax`
4. `04_resolution`

The four frames must use the same character continuity locks and must not be
created by copying a single keyframe. The catalog contains twelve four-frame
sequences (48 PNGs). Asset-level approval does not imply canonical story
mapping, Godot integration, or current-build QA. Only
`echo_002_zekranu_totem_choice` is referenced by the runtime, and its current
prototype trigger is not canonical.

See `docs/production/M30_ASSET_COVERAGE.md` for M30 asset-to-quest candidates
and unresolved mappings.

The single-frame images in the parent `scenes/` directory are legacy keyframes
and are not considered complete sequences.
