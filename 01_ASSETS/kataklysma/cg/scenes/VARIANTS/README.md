# Narrative CG variants

Production CGs live here. Every scene must contain four distinct images:

1. `01_start`
2. `02_development`
3. `03_climax`
4. `04_resolution`

The four frames must use the same character continuity locks and must not be
created by copying a single keyframe. The current approved sequence is:

`echo_002_zekranu_totem_choice`

The single-frame images in the parent `scenes/` directory are legacy keyframes
and are not considered complete sequences.
