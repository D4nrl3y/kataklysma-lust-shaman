# Echo Isles SFX

Place release-approved `.ogg` one-shots here. `audio_manager.gd` looks for these exact event names:

- `menu_select.ogg`
- `quest_accept.ogg`
- `quest_complete.ogg`
- `combat.ogg`
- `error.ogg`

Until those recordings are authored and approved, the runtime keeps its procedural tone fallback. This directory does not contain final SFX yet.
